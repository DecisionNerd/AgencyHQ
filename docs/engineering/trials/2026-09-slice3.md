## Findings and fixes

These findings arose during the Slice 3 trial and changed code or design documentation.

1. **Zero base revision on seeded projects.** The seeded project carried a zero base revision so `git worktree add` failed before any model call and the reconciler never closed the stalled dispatch intent. Fix (`720dfe9`): the flow resolves HEAD of the project's clone when no stored revision exists; the seed script stores the repository HEAD; the reconciler closes `observed` intents whose `lead.plan` run ended `FAILED` and records an execution Failure. Handler errors are logged instead of swallowed.

2. **Reconciler did not close failed plan intents.** A dispatch intent whose `lead.plan` run ended `FAILED` was never closed, leaving it re-polled forever. Fix: included in `720dfe9` above.

3. **Profile catalog not in Lead payload.** The Lead invented a verification profile id because the project's profile catalog was not present in the `lead.plan` payload. Fix (`a4f23e4`, `ade8987`): the profile catalog is now part of the `lead.plan` payload; the prompt requires `profileId` to be one of the catalog ids; a proposal naming a profile outside the catalog is recorded as `pending_human` with `PROFILE_NOT_IN_CATALOG` instead of freezing a contract whose checks do not exist.

4. **Worker output envelope.** The `worker.attempt` task at the Slice 1 code level emitted the spike's output envelope, which lacked `sessionId` and the worker report. Fix (`787ca44`): the output now includes the OpenCode session id and a `WorkerReport` (final message and touched paths, context for the Lead, never evidence), matching `WorkerAttemptOutputSchema`.

5. **`humanRequired` gates acceptance, not dispatch.** The flow initially guarded dispatch on `humanRequired`; the EXECUTION_MODEL specifies it gates acceptance (step 8). Fix: applied at merge of commit `2979bf6`.

6. **StructuredOutput tool allowance.** Lead sessions require OpenCode's `StructuredOutput` tool to be allowed; without it the JSON loop never completes. Fix: applied at merge of commit `2979bf6` (`ad11acd` earlier).

## Design findings

- **Profile catalog is an authority ceiling.** The Lead may only propose a `profileId` that appears in the project's verification profile catalog. An invented or unlisted profile id yields `PROFILE_NOT_IN_CATALOG` and is not retried automatically. This is now recorded in ARCHITECTURE.md and DOMAIN_MODEL.md.
- **Final run status precedes adapter cleanup.** Already recorded in the Slice 1 record and EXECUTION_MODEL.md.
- **`humanRequired` gates acceptance, not dispatch.** Step 8 of the lifecycle in EXECUTION_MODEL.md.
